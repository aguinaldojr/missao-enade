# Pacote do piloto — N9 Jornada Digital

Este diretório reúne os instrumentos para um teste controlado do MVP, sem coleta automática e sem envio de dados pela aplicação.

- [Roteiro de aplicação](roteiro-piloto-n9.md): preparação, distribuição das partidas, condução, critérios e encerramento.
- [Formulário de feedback](formulario-feedback-piloto.md): modelo anônimo para estudantes, professores e observação da sessão.

O nome N9 é provisório e não representa aprovação institucional. O piloto não deve ser apresentado como avaliação oficial, prova ou produto publicado.
